# 各省质态异常与管控处置汇总

- **类型**：质态分析 + 策略调控（多省汇总，按省份分节）
- **维护规则**：本文件为**唯一**汇总案例（不再按省拆文件）；每次分析完在对应省分节追加，或新增省分节
- **状态**：🟢 持续维护
- **原始台账**：`~/月度质态异常分析记录.md`（逐次分析留痕）；工作记录表：本地库 `work_log.work_record`

## 通用口径（复用优先，各省一致）
- **数据源**：`dws.dws_credit_yzf_order_complete`（竣工宽表）、`ods.ods_ts_order_white_list_control`（风控表）、源库 `taoshun_fenqi.credit_yzf_order_grant_apply`（实时申请表）、bl `bailv_np` 配置表
- **业务**：`source_business_type='淘顺实时授信'`；公众 `custtype='00'`
- **逾期定义**：🔴 `lmd_step_num_repay_status=2` + `order_status='已竣工'`（**不要用** `step_num_repay_status`，约 9% 误报）
- **本异网**：DWS `operator_real` 是数字编码（`3`=本网电信、`1`=移动、`2`=联通、NULL=异常）；风控表是文本（电信/移动/联通）
- **金额**：`remaining_principal` 单位分（/100）；`order_amt_yuan` 已是元
- **源库坑**：源库申请表 `apply_status` 是**中文**（授信成功/授信失败）、无 `source_business_type`（用 `business_type='02'`）、无新老客/本异网字段
- **套餐浮动**：`risk_pack_name_control.pass_ratio` 为**加法**（实际通过率 = 原通过率 + pass_ratio），-0.4 = 减 40pp；该表 id 非自增，INSERT 需显式取 max(id)+1
